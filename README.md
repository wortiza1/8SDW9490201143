# Tarea 4 - Tienda en línea

Aplicación desarrollada con React y conectada a un backend con Node.js, Express y MongoDB Atlas.

## Funciones

- Registro e inicio de sesión de clientes.
- Consulta del perfil del usuario.
- Catálogo de productos y carrito.
- Creación, edición y eliminación de productos para administradores.

## Tecnologías

- React y React-Bootstrap.
- Context API + useReducer para el estado global (Opción A de la Tarea 3).
- Node.js, Express y Mongoose.
- MongoDB Atlas.
- JWT para la autenticación y bcrypt para guardar las contraseñas como hash.
